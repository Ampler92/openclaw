# Frontend Starter

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Features

- Live match list with real-time updates
- Match details view
- Statistics dashboard
- Responsive design

## API Integration

Connect to backend API at `http://localhost:8000`
